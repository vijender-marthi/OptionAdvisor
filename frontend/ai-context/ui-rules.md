# UI Rules

- Dark trading dashboard style.
- Avoid clutter; present concise information.
- Use cards for summary views.
- Use expandable rows for detailed data.
- Use badges for engine, signal, risk, and alert status.
- Show strong warnings for AVOID / CRITICAL conditions.
- **Watchlist** – pre‑trade potential opportunities.
- **Positions Center** – post‑trade holdings.
- **Alert Center** – all alerts.
- **Trade Command Center** – decision page.
- Do not duplicate business logic in the UI; it must call the backend.
